# TravelTech – система совместного планирования групповых поездок

Проект представляет собой спецификацию веб-сервиса для семейного или дружеского планирования поездок. Система позволяет нескольким участникам одновременно добавлять рейсы, отели, активности, синхронизировать изменения, разрешать конфликты голосованием и интегрироваться с российскими провайдерами (СИРЕНА, Яндекс.Авиа, Ostrovok.ru и др.).

## Цель проекта

Создать детальную спецификацию для разработки сервиса совместного планирования, учитывающую:
- многопользовательский режим с правами организатора и участников;
- офлайн-режим и синхронизацию изменений;
- интеграцию с внешними API (авиа, отели, активности, платежи) с приоритетом российских провайдеров;
- прозрачный процесс разрешения конфликтов через голосование;
- безопасную обработку персональных данных и документов.
