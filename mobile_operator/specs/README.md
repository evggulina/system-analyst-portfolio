# Спецификация API (OpenAPI)

В этой папке находится спецификация REST API для проекта **«Мой мобильнй оператор»**. Спецификация разработана в формате OpenAPI и служит контрактом между клиентом и сервером.

## 📄 Состав

- [**OpenAPI спецификация**](openapi.yaml) – описание всех эндпоинтов, моделей запросов и ответов.
- [**Интерактивная документация в Swagger UI**](https://evggulina.github.io/system-analyst-portfolio/mobile_operator/specs/) – интерактивная спецификация с помощью встроенного Swagger UI для удобного тестирования и изучения API.
