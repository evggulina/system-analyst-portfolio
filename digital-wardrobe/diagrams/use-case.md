# Вариант использования: Добавить вещь в гардероб

| **Идентификатор** | ВИ-ПФ-001 |
|-------------------|-----------|
| **Название**      | Добавить вещь в гардероб |
| **Краткое описание** | Пользователь добавляет фото одежды, заполняет её атрибуты и сохраняет вещь в своём цифровом гардеробе. |
| **Действующие лица** | Пользователь |
| **Триггер**       | Пользователь нажимает кнопку «Добавить вещь» |
| **Предусловие**   | • Пользователь успешно авторизован в системе.<br>• Предоставлен доступ к камере (для мобильной версии). |

---

## Основной поток (успешный сценарий)

1. Пользователь нажимает кнопку **«Добавить вещь»**.
2. Система открывает **экран добавления** с формой для заполнения.
3. Пользователь нажимает на область загрузки изображения.
4. Система предлагает выбрать фото (для ПК — стандартный диалог, для мобильной версии см. альтернативный поток **А1**).
5. Пользователь выбирает фотографию.
6. Система отображает выбранное изображение в форме.
7. Пользователь заполняет поля:
   - **Обязательные**: Название, Категория.
   - **Опциональные**: Бренд, Цвет, Сезон, Стиль.
8. Пользователь нажимает кнопку **«Сохранить»**.
9. Система проверяет введённые данные (валидация).
10. Система сохраняет новую вещь.
11. Вариант использования завершается.

---

## Альтернативные потоки

### А1. Мобильная версия (вместо шага 4)
1. Система предлагает выбрать фото из галереи или сделать снимок камерой.
2. Пользователь выбирает способ загрузки.
3. После успешной загрузки — переход к **шагу 6** основного потока.

### А2. Неподдерживаемый формат фото (после шага 5)
1. Система показывает сообщение: *«Не удалось загрузить изображение. Попробуйте ещё раз»*.
2. Пользователь повторяет выбор фото.
3. При успехе — переход к **шагу 6**.

### А3. Не заполнены обязательные поля (на шаге 9)
1. Система сообщает: *«Пожалуйста, заполните обязательные поля»*.
2. Возврат к **шагу 7** (повторное заполнение).

---

## Потоки исключения

### Е1. Отмена добавления (на любом шаге 3–8)
1. Пользователь нажимает **«Отмена»**.
2. Система запрашивает подтверждение: *«Все несохранённые изменения будут потеряны. Продолжить?»*
3. При подтверждении — закрытие экрана без сохранения.
4. Вариант использования завершается досрочно.

### Е2. Ошибка сети (на шаге 10)
1. Система показывает сообщение: *«Сервис временно недоступен. Попробуйте позже»*.
2. Вариант использования завершается досрочно.

---

## Постусловие и результат

- **Постусловие:** Система показывает уведомление *«Вещь успешно добавлена в гардероб!»*.
- **Результат:** Новая вещь отображается в общем списке гардероба, пользователь возвращается на главный экран.
