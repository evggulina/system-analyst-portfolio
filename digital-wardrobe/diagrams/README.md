# Диаграммы проекта "Цифровой гардероб"

В этой папке находятся все диаграммы, созданные в ходе работы.  
Файлы представлены в двух форматах: .drawio, .puml(исходники) и .png (для быстрого просмотра).

| Имя файла | Тип диаграммы | Описание |
|-----------|---------------|----------|
| [use-case.drawio](use-case.drawio) / [use-case.png](use-case.png)| Use Case | Показывает акторов и их взаимодействие с системой. Основные сценарии: регистрация / авторизация, добавление, просмотр, редактирование и удаление вещей, создание, просмотр, редактирование образов вручную, генерация образов, рекомендации по дополнению образа, поиск магазинов.|
| [class-diagram.drawio](class-diagram.drawio) / [class-diagram.png](class-diagram.png) / [class-diagram.puml](class-diagram.puml) | Классов | Модель данных: основные сущности и их связи. |

## 🔧 Инструменты
- Исходники .drawio открываются в [draw.io](https://app.diagrams.net/).
- Для просмотра .png достаточно любого браузера или программы для просмотра изображений.
- .puml — текстовое описание диаграмм (PlantUML), можно открыть в любом текстовом редакторе или сгенерировать изображение через [PlantUML сервер](https://www.plantuml.com/plantuml/uml/)
