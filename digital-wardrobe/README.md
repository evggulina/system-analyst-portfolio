# Проект "Цифровой гардероб"

В рамках практики самостоятельно выполнила анализ и проектирование для реального заказчика (стартап в области fashion-tech) - приложения для управления личным гардеробом с возможностью создания образов и ИИ-рекомендаций.

## Цель проекта
Разработать спецификацию функциональности «Добавление вещи в гардероб» с учётом дальнейшей передачи в разработку.

## Моя роль
Системный аналитик (стажёр). 
- сбор и структурирование требований 
- спроектировала модель данных, REST API  
- подготовила тестовые сценарии в Postman.
