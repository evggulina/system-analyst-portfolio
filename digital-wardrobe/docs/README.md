# Документация проекта «Цифровой гардероб»

В этой папке находятся артефакты анализа и проектирования функциональности **«Добавление вещи в гардероб»** для стартапа в области fashion-tech. Материалы подготовлены в рамках стажёрской практики (роль: системный аналитик).

## 📄 Состав документации

- **[Основная спецификация](requirements.md)** — документ, объединяющий функциональные требования, сценарии использования (основной и альтернативные потоки) для use-case «Добавить вещь», а также описание модели данных.
- **[Модель данных](data-model.md)** — подробное описание сущностей `User`, `WardrobeItem`, `Category`, `Image`, их атрибутов и связей. Визуализация представлена на [диаграмме классов](/diagrams/class-diagram.png).
- **[Вариант использования «Добавить вещь»](use-case.md)** — детальное описание основного и альтернативных сценариев добавления предмета одежды в гардероб. Use-case диаграмма доступна [здесь](use-case.png).

## 🔍 Назначение

Документация предназначена для разработчиков, тестировщиков и всех участников команды, чтобы обеспечить единое понимание функциональности, структуры данных и логики работы модуля добавления вещей. Спецификация служит основой для реализации и дальнейшего развития системы, включая будущие ИИ-рекомендации по созданию образов.
