# Глоссарий

**БТ** — бизнес-требование

**ПТ** — пользовательское требование

**НФТ** — нефункциональное требование

## Бизнес-требования

| Код     | Описание |
|---------|----------|
| БТ-001  | Необходимо разработать программное обеспечение цифрового гардероба, которое позволит пользователям загружать и сохранять фотографии предметов одежды. |
| БТ-002  | Необходимо интегрировать ИИ-стилиста, с помощью которого пользователь сможет собирать вещи в готовые образы, а также дополнять их различными аксессуарами с рекомендациями, где их можно приобрести. |

## Пользовательские требования

| Код     | Описание |
|---------|----------|
| ПТ-001  | Пользователь должен иметь возможность регистрироваться в цифровом гардеробе. |
| ПТ-002  | Пользователь должен иметь возможность загрузить фото вещи в цифровой гардероб с персонального компьютера (ПК). |
| ПТ-003  | Пользователь должен иметь возможность загрузить фото вещи в цифровой гардероб из галереи телефона. |
| ПТ-004  | Пользователь должен иметь возможность загрузить фото вещи в цифровой гардероб с помощью камеры телефона. |
| ПТ-005  | Пользователь должен иметь возможность указывать различные атрибуты для вещей (название, сезон, категория, цвет, бренд итд). |
| ПТ-006  | Пользователь должен иметь возможность собирать вещи в готовые образы. |
| ПТ-007  | Пользователь должен иметь возможность сохранять новую вещь в гардеробе. |
| ПТ-008  | Пользователь должен иметь возможность редактировать вещь в гардеробе. |
| ПТ-009  | Пользователь должен иметь возможность удалять вещь из гардеробе. |
| ПТ-010  | Пользователь должен иметь возможность фильтровать вещи в гардеробе. |
| ПТ-011  | Пользователь должен иметь возможность генерировать готовые образы из загруженных фото с помощью ИИ-стилиста. |
| ПТ-012  | Пользователь должен иметь возможность составлять готовый образ из загруженных фото самостоятельно. |

## Нефункциональные требования

*Производительность*

| Код     | Описание |
|---------|----------|
| НФТ-001 | Время отклика API (95% запросов) не должно превышать 200–300 мс. |
| НФТ-002 | Загрузка изображений (до 10 МБ) должна занимать не более 2–3 секунд при хорошем соединении. |
| НФТ-003 | Система должна выдерживать пиковые нагрузки (например, 1000 одновременных пользователей) без деградации производительности. |

*Безопасность*

| Код     | Описание |
|---------|----------|
| НФТ-004 | Все соединения должны использовать HTTPS. |
| НФТ-005 | Пароли пользователей хранятся в захэшированном виде. |
| НФТ-006 | JWT-токены должны иметь ограниченное время жизни (например, 24 часа) и обновляться через refresh-токены. |
| НФТ-007 | Доступ к ресурсам должен проверяться: пользователь может видеть/редактировать только свои вещи и образы. |

*Надёжность и доступность*

| Код     | Описание |
|---------|----------|
| НФТ-008 | Доступность сервиса — 99.5% на начальном этапе, с возможностью повышения до 99.9%. |
| НФТ-009 | Автоматическое резервное копирование базы данных ежедневно, хранение копий не менее 7 дней. |
| НФТ-010 | При сбоях система должна возвращать понятные сообщения об ошибках и не терять данные. |

*Масштабируемость*

| Код     | Описание |
|---------|----------|
| НФТ-011 | База данных должна поддерживать горизонтальное масштабирование (шардинг или репликацию) для роста числа пользователей. |
| НФТ-012 | Архитектура должна позволять добавлять новые сервисы (например, рекомендательную систему). |
| НФТ-013 | Хранение изображений — использовать облачное объектное хранилище с CDN для быстрой доставки. |

*Удобство использования*

| Код     | Описание |
|---------|----------|
| НФТ-014 | Интерфейс должен быть адаптивным и корректно отображаться на основных размерах экранов (мобильные устройства, планшеты, десктопы). |
| НФТ-015 | Максимальное время обучения новому пользователю — не более 5 минут для выполнения базовых действий (добавить вещь, создать образ). |

*Совместимость*

| Код     | Описание |
|---------|----------|
| НФТ-016 | Веб-версия должна работать в последних версиях Chrome, Firefox, Safari, Edge. |
| НФТ-017 | Мобильное приложение (если планируется) — поддержка iOS (последние 2 версии) и Android (последние 3 версии). |

*Требования к данным*

| Код     | Описание |
|---------|----------|
| НФТ-018 | Изображения должны храниться в оптимизированном формате (например, WebP) с автоматическим сжатием. |
| НФТ-019 | Пользователь имеет право удалить свои данные. |
| НФТ-020 | Реализовать полное удаление аккаунта со всеми связанными данными. |

*Интеграция*

| Код     | Описание |
|---------|----------|
| НФТ-021 | API должно быть документировано в формате OpenAPI (Swagger) и доступно для ознакомления разработчикам. |
| НФТ-022 | Интеграция с внешними сервисами (магазины, ИИ) должна быть отказоустойчивой: при недоступности внешнего сервиса возвращать понятную ошибку и не ломать основную функциональность. |
