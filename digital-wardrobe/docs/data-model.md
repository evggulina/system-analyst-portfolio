# Модель данных

## Таблица users

| Поле        | Тип           | Обязательное | Валидация / Примечания |
|-------------|---------------|--------------|------------------------|
| id          | uuid          | Да           | Первичный ключ, генерируется автоматически. |
| first_name  | varchar(255)  | Да           | Не пустое, только буквы, пробелы и дефисы. Длина 1–255 символов. |
| last_name   | varchar(255)  | Да           | Не пустое, только буквы, пробелы и дефисы. Длина 1–255 символов. |
| email       | varchar(255)  | Да           | Уникальное. Должно соответствовать формату email (например, user@example.com). |
| created_at  | timestamp with time zone | Да | Автоматически устанавливается при создании. |

## Таблица categories

| Поле | Тип         | Обязательное | Валидация / Примечания |
|------|-------------|--------------|------------------------|
| id   | serial      | Да           | Первичный ключ, автоинкремент. |
| key  | varchar(50) | Да           | Уникальное. Только латиница, цифры и подчёркивания (например, upper_body). Длина 1–50 символов. |
| name | varchar(100)| Да           | Уникальное. Название категории (например, «Верх»). Длина 1–100 символов. |

## Таблица subcategories

| Поле        | Тип          | Обязательное | Валидация / Примечания |
|-------------|--------------|--------------|------------------------|
| id          | serial       | Да           | Первичный ключ, автоинкремент. |
| key         | varchar(50)  | Да           | Уникальное в пределах категории? Рекомендуется уникальность в связке с category_id. Только латиница, цифры, подчёркивания. Длина 1–50 символов. |
| name        | varchar(100) | Да           | Название подкатегории (например, «Футболка»). Длина 1–100 символов. |
| category_id | integer      | Да           | Внешний ключ к categories(id). Каскадное удаление (on delete cascade). |

## Таблица seasons

| Поле | Тип         | Обязательное | Валидация / Примечания |
|------|-------------|--------------|------------------------|
| id   | serial      | Да           | Первичный ключ, автоинкремент. |
| name | varchar(50) | Да           | Уникальное. Фиксированный набор: «Любой», «Лето», «Зима», «Демисезон». Может быть расширен администратором. |

## Таблица styles

| Поле | Тип         | Обязательное | Валидация / Примечания |
|------|-------------|--------------|------------------------|
| id   | serial      | Да           | Первичный ключ, автоинкремент. |
| name | varchar(50) | Да           | Уникальное. Примеры: «повседневная», «деловая», «спортивная», «вечерняя». Список может пополняться. |

## Таблица items

| Поле           | Тип                    | Обязательное | Валидация / Примечания |
|----------------|------------------------|--------------|------------------------|
| id             | uuid                   | Да           | Первичный ключ, генерируется автоматически. |
| user_id        | uuid                   | Да           | Внешний ключ к users(id). Каскадное удаление (on delete cascade). |
| image_url      | varchar(500)           | Да           | Корректный URL (http:// или https://). Длина до 500 символов. |
| name           | varchar(100)           | Да           | Не пустое. Длина 1–100 символов. |
| category_id    | integer                | Да           | Внешний ключ к categories(id). |
| subcategory_id | integer                | Нет          | Внешний ключ к subcategories(id). Должен соответствовать category_id (проверка на уровне приложения). |
| brand          | varchar(100)           | Нет          | Длина до 100 символов. |
| color          | varchar(50)            | Нет          | Длина до 50 символов. |
| season_id      | integer                | Нет          | Внешний ключ к seasons(id). При удалении сезона проставляется NULL (on delete set null). |
| style_id       | integer                | Нет          | Внешний ключ к styles(id). При удалении стиля проставляется NULL. |
| created_at     | timestamp with time zone | Да         | Автоматически устанавливается при создании. |
| updated_at     | timestamp with time zone | Да         | Автоматически обновляется при изменении записи. |

### Дополнительные правила для изображения (файла)
- Допустимые форматы: JPEG, PNG, WebP.
- Максимальный размер файла: 10 МБ.
- Минимальные размеры: 200×200 пикселей (опционально, для качества отображения).

## Таблица outfits

| Поле        | Тип                    | Обязательное | Валидация / Примечания |
|-------------|------------------------|--------------|------------------------|
| id          | uuid                   | Да           | Первичный ключ, генерируется автоматически. |
| user_id     | uuid                   | Да           | Внешний ключ к users(id). Каскадное удаление. |
| name        | varchar(100)           | Да           | Не пустое. Длина 1–100 символов. |
| description | text                   | Нет          | Текстовое описание, максимальная длина не ограничена (но рекомендуется до 1000 символов для UI). |
| created_at  | timestamp with time zone | Да         | Автоматически устанавливается. |
| updated_at  | timestamp with time zone | Да         | Автоматически обновляется. |

## Таблица outfit_items

| Поле      | Тип    | Обязательное | Валидация / Примечания |
|-----------|--------|--------------|------------------------|
| outfit_id | uuid   | Да           | Внешний ключ к outfits(id). Каскадное удаление. |
| item_id   | uuid   | Да           | Внешний ключ к items(id). Каскадное удаление. |

### Ограничения
- Первичный ключ: (outfit_id, item_id).
- Уникальность пары гарантирует, что одна вещь не может быть добавлена в один образ дважды.
- Дополнительное бизнес-правило (проверяется в приложении): вещь должна принадлежать тому же пользователю, что и образ.
