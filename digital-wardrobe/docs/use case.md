# Пример сценария использования (Use case)

## Идентификатор и название варианта использования
ВИ-ПФ-001 Добавить вещь в гардероб

## Краткое описание
Пользователь добавляет фото одежды, заполняет ее атрибуты и сохраняет вещь в своём цифровом гардеробе.

## Действующие лица
Пользователь

## Триггер
Пользователь нажимает кнопку «Добавить вещь»

## Предусловие
- Пользователь успешно авторизован в системе.
- Предоставлен доступ к камере (при использовании программного обеспечения для мобильного телефона)

## Основной поток
1. Пользователь нажимает кнопку «Добавить вещь».
2. Система открывает экран добавления новой вещи с формой для заполнения.
3. Пользователь нажимает на область для загрузки изображения.
4. **Если** пользователь использует версию программного обеспечения для ПК, управление переходит на следующий шаг.
5. Система предлагает выбрать фото.
6. Пользователь выбирает фотографию.
7. **Если** изображение успешно добавлено, управление переходит на следующий шаг.
8. Система отображает выбранное изображение в форме.
9. Пользователь заполняет поля: Название, Категория.
10. Пользователь по желанию заполняет поля: Бренд, Цвет, Сезон, Стиль.
11. Пользователь нажимает кнопку «Сохранить».
12. Система проверяет введенные данные.
13. **Если** проверка (валидация) пройдена успешно, управление переходит на следующий шаг.
14. Система сохраняет новую вещь.
15. **Если** новая вещь сохранена успешно, управление переходит на следующий шаг.
16. Вариант использования завершает свою работу.

## Альтернативные потоки

### 4а. Пользователь использует мобильную версию программного обеспечения
1. Система предлагает выбрать фото из галереи или воспользоваться камерой.
2. Пользователь выбирает удобный ему вариант для загрузки фото.
3. **Если** загрузка фотографий прошла успешно, управление переходит на шаг 8.

### 7а. Неподдерживаемый формат фотографии
1. Система показывает сообщение «Не удалось загрузить изображение. Попробуйте еще раз».
2. Система предлагает заново выбрать фотографии в поддерживаемом формате.
3. **Если** загрузка фотографий прошла успешно, управление переходит на шаг 8.

### 13а. Не заполнены обязательные поля (Название, Категория)
1. Система сообщает «Пожалуйста, заполните обязательные поля».
2. Управление переходит на шаг 9.

## Потоки исключения

### Пользователь отменяет добавление
В любой момент на шагах 3–11 пользователь может нажать «Отмена».
1. Система запрашивает у пользователя подтверждение отмены добавления вещи в гардероб.
2. Система предупреждает об утере внесенных данных («Все несохраненные изменения будут потеряны»).
3. При подтверждении система закрывает экран добавления без сохранения.
4. Вариант использования завершает свою работу.

### 7а, 15. Ошибка сети
1. Система показывает сообщение «Сервис временно недоступен. Попробуйте позже».
2. Вариант использования завершает свою работу.

## Постусловие
Система показывает уведомление «Вещь успешно добавлена в гардероб!»

## Результат
Система возвращает пользователя в его гардероб, где новая вещь отображается в общем списке.
